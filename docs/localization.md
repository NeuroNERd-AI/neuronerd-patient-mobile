# Localization and accessibility

The i18n catalog contains English, Hindi, Assamese, and Bengali keys with English fallback. The design tokens use large body text, patient-friendly copy, large touch targets, explicit labels, icon-plus-text navigation, and no required countdowns. Buttons expose accessibility roles and labels; game choices expose labels and use more than color to communicate state.

Large-text and high-contrast theme tokens are present in the profile settings foundation. Full screen-by-screen reflow, TalkBack focus audits, and long-string device validation remain physical-device release checks.
